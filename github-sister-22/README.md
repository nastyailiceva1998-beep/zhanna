# Atelier 22

Birthday adventure with architecture, art and Frosya.

Static website: open `index.html` locally, or publish with GitHub Pages.

## GitHub Pages

1. Upload this directory's contents into the `main` branch of a new repository.
2. In Settings > Pages, select GitHub Actions as the source.
3. Run the Publish birthday site workflow from the Actions tab.

Later pushes to `main` publish automatically. All website assets use relative
paths, so the site works at a repository-specific GitHub Pages URL.
